# 可执行的智慧 · Executable Wisdom

一部从古代计算术到现代科学工程、可以亲手运行的算法文明史。

当前原型包含项目首页、历史主线、独立MDX章节和一个可交互的欧几里得算法实验。

## 本地开发

```bash
npm install
npm run dev
```

默认地址为 `http://localhost:4321/`。

## 发布

项目采用 Astro + MDX + React，并已经配置 GitHub Pages 自动发布。推送到 GitHub 的 `main` 分支后，在仓库设置中将 Pages 的发布来源选为 **GitHub Actions**，读者即可通过网页直接阅读。

## 产品原则

- 计算机不是主角；真实问题和解决问题的方法才是。
- 从不同文明的古代计算传统出发，延伸到科学、工程、医学、通信、生命与社会。
- 每一章形成“问题—预测—执行—反例—解释—证明”的浏览器内闭环。
- 核心实验无需账号、服务器或大型计算资源。
- 历史事实、数学结论、教学解释和作者推断在内容中明确区分。

完整技术路线见 `docs/architecture.md`。
