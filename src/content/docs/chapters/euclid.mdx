## 现实任务：做一把尽可能长的尺

两段绳子分别长 252 和 105 个单位。我们希望只用一种长度的尺子量完它们，而且这把尺子要尽可能长。这里的“量完”意味着不能留下余段，“尽可能长”则意味着少量几次就能完成工作。

现实问题里还有许多没有说出的细节：绳子会不会伸缩？读数精确到哪里？允许留下多大的误差？这一章先研究理想化的整数长度，稍后再回来检查这个选择。

## 从铺尺动作到整数模型

我们把两段长度抽象为正整数 `a` 和 `b`，把可重复使用的尺长记作 `d`。如果尺子能无剩余地量完两段绳子，那么 `d` 必须同时整除 `a` 和 `b`；如果还希望它尽可能长，目标就变成寻找最大的公因数：`gcd(a, b)`。

这一步才把生活中的“做尺子”变成数学问题。若任务改成“允许 1 毫米误差”或“尽量减少切割损耗”，目标与约束都会改变，欧几里得算法也不再直接回答原问题。

## 历史现场

《几何原本》第七卷研究“数”。命题 1 用连续互减直到留下单位的过程判断两个数互素；命题 2 则要求找出两个非互素数的最大公度。文本的动作是：较小者反复从较大者中扣除，余下的量再去量前一个量，直到某个余量恰好量尽它的前项。

这和现代程序里一次计算 `a mod b` 并不完全相同。余数运算把多次减法压缩成了一次除法：`a = q × b + r`。两者利用同一公因数结构，但本书不会把现代符号倒写进古代原文，也不会断言欧几里得是这个过程最早的发明者；《几何原本》是重要的现存系统文本，不等于思想的唯一源头。

## 从模型到可计算问题

输入是两个正整数，输出是它们的最大公约数。逐个测试 1、2、3……当然可以，但它没有利用问题的结构。更好的问题是：**能否把这两个数换成一对更小的数，同时保证答案不变？**

现代余数版本可以写得很短：

```text
gcd(a, b):
  要求 a > 0 且 b > 0
  当 b ≠ 0：
    (a, b) ← (b, a mod b)
  输出 a
```

这段伪代码需要回答两件不同的事：每一步是否保存答案，以及循环是否一定停止。

## 为什么可以保留余数？

假设 `a = q × b + r`。任何同时整除 `a` 和 `b` 的数，也一定整除 `a - q × b`，而这个差正是 `r`。反过来也成立，因此：

> `gcd(a, b) = gcd(b, a mod b)`

这一条在每一步都保持不变的事实，叫作**不变量**。算法并不是碰巧得到答案；它在不断缩小数字的同时，小心地保存着答案。当余数成为零，最后一个非零除数就是最大公约数。

把“反过来也成立”展开，会看到证明的对称性。若 `d` 同时整除 `a` 与 `b`，它也整除 `a - q × b = r`；若 `d` 同时整除 `b` 与 `r`，它也整除 `q × b + r = a`。两对数拥有完全相同的公因数集合，所以最大的一个也相同。

## 为什么一定会停止？

除以正整数 `b` 得到的余数总满足 `0 ≤ r < b`。因此，每轮循环的第二个数都是一个更小的非负整数。非负整数不可能严格下降无穷多次，最终必然到达 0。

此时不变量给出 `gcd(a, 0) = a`：所有能同时整除 `a` 与 0 的正整数，正是 `a` 的因数，其中最大的是 `a` 本身。正确性由“不变量 + 终止条件”合在一起得到，而不是只看几个例子。

## 哪些输入让它走得最慢？

如果每一步的商都很小，数字就缩得最慢。连续的斐波那契数恰好不断产生商为 1 的步骤。例如把实验输入改成 `233` 与 `144`，执行记录会沿着 `89, 55, 34, 21...` 下降。

输入的数值可能很大，但十进制位数只按其对数增长。欧几里得算法的除法次数与输入位数成正比量级，而不是与输入数值本身成正比。这是“利用结构”带来的巨大差别：对一个有上百位的整数，逐个枚举因数不可想象，辗转相除仍然实际可做。

## 双重验证：算对了，也建对了吗？

对整数模型而言，我们可以用不变量证明算法得到的确是最大公约数；还可以把结果重新代回，检查它能否整除两个输入。这验证的是**算法正确性**。

但若 252 和 105 来自带误差的实际测量，输入可能写成 252.1 和 104.9，精确公约数便失去意义。此时即使程序完全正确，答案也可能毫无用途。这要检查的是**模型有效性**：测量精度是否支持整数化？允许多大公差？真正目标是无缝铺满，还是减少材料种类？

## 模型失效时怎样改写问题

真实制造中可以把“整除”换成“余量不超过容差”，把“最长”与“废料最少”“接缝最少”等目标一起权衡。此时问题可能变成近似公约数、离散优化或带成本的切割问题。不是欧几里得算法突然失效了，而是我们终于承认：现实任务从来不等于最初写下的整数模型。

## 从公约数到现代基础设施

最大公约数并没有停留在古代算术里。化简分数需要约去分子分母的公因数；扩展欧几里得算法还能找到整数 `x, y`，使 `ax + by = gcd(a,b)`。当最大公约数为 1 时，这个关系给出模逆元，而模逆元是 RSA 等公钥密码计算中的基本工具之一。

这条现代联系不是“古希腊人发明了互联网密码学”，而是同一数学结构在新模型里获得了新用途。历史连续性属于思想结构，不应被讲成一条简单的英雄传承线。

## 本章练习

1. 不运行实验，写出 `gcd(391, 299)` 的每一步，再用反向代入检查答案。
2. 在等式 `a = q × b + r` 中，分别证明“共同整除 `a,b`”和“共同整除 `b,r`”互相推出。
3. 比较 `gcd(256, 128)` 与 `gcd(233, 144)` 的步骤数。数值更大是否必然更慢？
