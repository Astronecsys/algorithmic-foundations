# 可执行的智慧（工作名）

一部从古代计算术到现代科学工程、可以亲手运行的算法文明史。

当前原型包含项目首页、历史主线和一个可交互的欧几里得算法实验。书名、目录和视觉系统仍可演进。

## 本地开发

```bash
npm install
npm run dev
```

## 产品原则

- 计算机不是主角；真实问题和解决问题的方法才是。
- 从不同文明的古代计算传统出发，延伸到科学、工程、医学、通信、生命与社会。
- 每一章形成“问题—预测—执行—反例—解释—证明”的浏览器内闭环。
- 核心实验无需账号、服务器或大型计算资源。
- 历史事实、数学结论、教学解释和作者推断在内容中明确区分。

完整技术路线见 `docs/architecture.md`。
