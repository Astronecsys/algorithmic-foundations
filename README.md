# 可执行的智慧 · Executable Wisdom

> 一部从古代计算术到现代科学工程、可以亲手运行的算法文明史。

算法并不始于计算机，也不只存在于程序内部。人类很早就开始把测量、推理、搜索、逼近和协作写成可以重复执行的步骤。本书追随这些方法如何在不同文明中出现、传播和演变，并邀请读者亲手运行它们。

## 直接阅读

- [打开《可执行的智慧》](https://astronecsys.github.io/executable-wisdom/)
- [试读：欧几里得算法](https://astronecsys.github.io/executable-wisdom/chapters/euclid/)

网页无需安装、注册或大型计算资源。实验在浏览器中运行，可以修改输入、逐步执行、回退并观察算法保持了什么。

## 这本书关心什么

这里的主角不是计算机，而是人类解决问题的方法：

- 古代埃及、巴比伦、希腊、中国、印度与伊斯兰世界的计算传统
- 测量、插值、数值逼近与科学模拟
- 搜索、优化、调度与资源分配
- 导航、控制、几何与工程设计
- 压缩、纠错、通信与密码
- 医学成像、生物序列与基因组装
- 匹配、投票、公平分配与社会协作

机器学习不属于本书的主体。收录的核心算法都应当能够由普通读者在本地浏览器中完整运行和理解。

## 怎样学习一章

每章尽量形成同一个学习循环：

1. 遇见算法诞生时的真实问题。
2. 在运行之前预测下一步。
3. 修改输入，观察方法如何变化。
4. 主动制造边界情况或反例。
5. 从实验中发现不变量和核心思想。
6. 最后连接伪代码、复杂度与证明。

历史事实、数学结论、教学解释和作者推断会明确区分。日期或发明归属存在争议时，将保留“约”“现存最早证据”等历史学表述。

## 开发者说明

项目采用 Astro + Starlight + MDX + React：Starlight 提供成熟的 Web Book 阅读框架，Astro 将正文预先生成成静态网页，MDX 用于章节写作，React 只负责需要互动的实验组件。

章节位于 `src/content/docs/chapters/`。如果在 `src/content/book.ts` 中加入新章节，可以执行 `npm run generate:chapters` 为缺少正文文件的章节生成内容骨架；已有书稿和单独维护的欧几里得样板章不会被覆盖。

### 本地运行

需要 Node.js 22 或更新版本：

```bash
npm install
npm run dev
```

默认地址为 `http://localhost:4321/`。

构建与检查：

```bash
npm run check
npm run build
```

### 部署

仓库已经配置GitHub Pages工作流。推送到 `main` 分支后，GitHub Actions会自动构建并发布网站。

更完整的分层设计、步骤事件协议、内容结构和实施顺序见 [`docs/architecture.md`](docs/architecture.md)。
